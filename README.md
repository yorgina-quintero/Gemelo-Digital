# Gemelo digital propuesto: Biblioteca Simón Bolívar

Diagrama interactivo de la arquitectura propuesta del gemelo digital para la zona piloto
(Colecciones Especiales) de la Biblioteca Simón Bolívar, Universidad de Panamá.

La arquitectura tiene cinco capas: adquisición de datos, transmisión, modelado digital,
integración de datos y modelo, y servicios. El personal de conservación, mantenimiento y
administración revisa los avisos y decide; el aire no se controla automáticamente.
